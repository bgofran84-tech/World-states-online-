# 🌍 World States Online — V1

## تشغيل محلي
1. ثبّت Node.js 18+.
2. افتح المجلد.
3. نفّذ:
   npm install
   npm start
4. افتح:
   http://localhost:10000

## نشر على Render
- ارفع المشروع إلى GitHub.
- في Render اختر New → Web Service.
- اربط المستودع.
- Build Command: `npm install`
- Start Command: `npm start`
- لا تحتاج قاعدة بيانات لهذه النسخة التجريبية.

## ملاحظات V1
- الغرف حقيقية عبر WebSocket.
- رمز الغرفة يشارك بين الأصدقاء.
- اختيار الدولة مخفي عن الآخرين.
- حالة اللعبة الأساسية موجودة على السيرفر.
- البيانات الحالية محفوظة في ذاكرة السيرفر؛ إذا أعاد Render تشغيل الخدمة تختفي الغرف.
- V2 يمكن إضافة: حرب، تحالف، تجارة، تجسس، أحداث عشوائية، مؤقت للجولات، دردشة، وإعادة الاتصال.
